# Poppy's Scuttle Slugging

## Description

Poppy's Scuttle Slugging is a game where Poppy (the player) is tasked with hitting a Scuttle Crab as far as she can, earning gold along the way. After her wonderful whallop, she gets to spend that gold in the shop, getting stronger and unlocking new monsters for the Scuttle Crab to encounter along it's journey.

## Installation (Currently only on Windows)

### Windows Instructions:

1. Download the latest build [here](https://github.com/UltraDagon/PoppysScuttleSlugging/archive/refs/heads/main.zip).
2. Navigate to your Downloads folder in Windows File Explorer.
3. Find "PoppysScuttleSlugging-main.zip" and right click -> Extract All... -> Extract to your desired destination.
4. Find "main.exe" and run it!
